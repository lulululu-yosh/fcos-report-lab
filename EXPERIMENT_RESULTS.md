# Experiment Results

The FCOS and RetinaNet experiments on COCO val2017 have been completed.

Committed files:

- `outputs/metrics/`: final evaluation metrics
- `outputs/tables/`: analysis tables
- `outputs/README.md`: output directory documentation

Large reproducible files are not committed:

- COCO images and annotations
- pretrained model weights
- full raw detection JSON files if they exceed a reasonable GitHub size

The full raw outputs are kept locally and can be regenerated by running the evaluation scripts.
