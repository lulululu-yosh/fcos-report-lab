# Experiment Results

The FCOS and RetinaNet experiments on COCO val2017 have been completed.

Committed files:

- `outputs/metrics/`: final evaluation metrics
- `outputs/tables/`: analysis tables
- `outputs/README.md`: output directory documentation

Large reproducible files are not committed:

- COCO images and annotations
- pretrained model weights
- full raw detection JSON files if they exceed a reasonable GitHub size

The full raw outputs are kept locally and can be regenerated by running the evaluation scripts.

## Cross-dataset Transfer Evaluation

The project now includes a transfer evaluation entrypoint:

```bash
python -m fcos_report.evaluate_transfer --dataset voc --split val --model fcos --download
python -m fcos_report.evaluate_transfer --dataset voc --split val --model retinanet
python -m fcos_report.evaluate_transfer --dataset visdrone --split val --model fcos --limit 1000
python -m fcos_report.evaluate_transfer --dataset visdrone --split val --model retinanet --limit 1000
```

This uses COCO-pretrained weights directly, with no retraining and no fine-tuning. Only classes that can be mapped to COCO categories are evaluated. Main metrics are AP50 with continuous PR integration, Recall@0.50, Precision@0.50, per-class AP50, and approximate transfer retention.

VisDrone must be downloaded manually into `data/VisDrone/VisDrone2019-DET-val/`. The expected subfolders are `images/` and `annotations/`.
